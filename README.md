### GLFW + GLAD + modern OpenGL with C++ (MSVC and GCC)
#### Build (cmd.exe)
```sh
# Debug build
$ build.bat 01-triangle-a
or
$ build.bat 01-triangle-a debug

# Release build
$ build.bat 01-triangle-a release
```
#### Build and Run (cmd.exe)
```sh
$ call build.bat 01-triangle-a && build\bin\01-triangle-a.exe
```

#### Build (mingw-w64)
```sh
# Debug build
$ ./build.sh 01-triangle-a
or
$ ./build.sh 01-triangle-a debug

# Release build
$ ./build.sh 01-triangle-a release
```
#### Build and Run (mingw-w64)
```sh
$ ./build.sh 01-triangle-a && ./build/bin/01-triangle-a.exe
```
